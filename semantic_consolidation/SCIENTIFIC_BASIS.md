# Scientific basis and scope of route one

This file defines the selected semantic consolidation mechanism. Optional
scheduling, replay selection, and inference controls have a separate
[scientific specification](SECTION10.md) and
[verification record](SECTION10_ASSESSMENT.md).

The research question is whether temporary class-informed modulations can be
transferred into an ordinary classifier, and whether that transfer depends on
diffusion noise. These mechanisms are hypotheses to evaluate. Successful
execution, finite losses, or synthetic accuracy do not establish improved
continual learning.

## Connection between the research question and code

The method studies retention and adaptation in class-incremental learning with
generated replay. Joint generation/classification provides the platform;
modulation acquisition and transfer supply the mechanism being tested.

| Research requirement | Existing capability reused | Added mechanism |
|---|---|---|
| Configured, reproducible experiments | `common.config.Config`, common runtime/seed configuration | Route-specific validated configuration |
| CIFAR streams and class schedules | `common.dataloader.get_datasets`, common schedule resolution | No replacement dataset implementation |
| Joint diffusion classifier | `common.model.get_model`, existing DiT classifier and diffusion wrapper | Classification-projection modulation adapter |
| Learn new classes and preserve old ones | `common.train.train_model`, common continual learner, class expansion, generated replay, prior-task teacher | Explicit post-joint acquisition and consolidation phases |
| Classifier and denoiser retention | Existing classifier KD and noise KD | Reuse their class support, masks, and reductions |
| Temporary class-informed control | Existing classifier hidden Dense projection | Retained per-class bounded gains and biases |
| Transfer control into ordinary inference | Existing classification projection and head | Frozen acquired target, predictor, contrastive transfer |
| Continual evaluation | `common.continual_reporting`, existing clean/ensemble evaluation | Phase, memory, gradient-ownership, and hidden-feature diagnostics |

The implementation reuses shared training and replay APIs so comparisons can
hold architecture, data exposure, and optimization settings fixed.

## Relation to the primary methods

[TMCL, NeurIPS 2025](https://proceedings.neurips.cc/paper_files/paper/2025/file/dd1fef536655685898a6602bfbf16857-Paper-Conference.pdf) learns class-specific affine modulations on frozen feedforward weights using one-versus-rest cosine separation. Its consolidation combines view invariance with modulation invariance and uses a predictor and stopped modulated targets. Its modulations are not required for inference. Its sparsely supervised continual representation-learning protocol and post-hoc readout evaluation differ from the incrementally trained classifier here. This implementation further differs in its bounded late-projection modulation, generated image replay, independently frozen acquired target, and noise weighting. It is an adaptation, not a TMCL reproduction.

The `tmcl` image-augmentation mode ports the transforms and parameters from
[Appendix A of the author manuscript](https://arxiv.org/html/2505.14125v3#A1).
Acquisition uses horizontal flips with probability 0.5. Consolidation uses
32 x 32 bicubic random resized crops with scale `(0.08, 1.0)` and aspect ratio
`(0.75, 4/3)`, random-order brightness/contrast/saturation/hue jitter
`(0.4, 0.4, 0.2, 0.1)` with probability 0.8, grayscale with probability 0.2,
horizontal flips with probability 0.5, and solarization on views 2, 4, ...
(one-based numbering) with probability 0.2, effective intensity threshold 0.5
and addition 0. Kornia's `thresholds=0.0` argument represents this fixed 0.5
threshold. Transforms operate in `[0,1]`, converting from and back to the
platform's nominal `[-1,1]` scale; bicubic overshoot is not clipped afterwards.
This follows the published policy; the author code differs in acquisition
cropping and ordering of solarized views. Native TensorFlow operations can
differ numerically from Kornia, and the crop uses ten sampling attempts with a
center-crop fallback rather than reproducing backend sampling quirks. This adds
independent image views to local modulation-target transfer; it does not add
the separate TMCL view-invariance loss or reproduce the full algorithm in
[Appendix C](https://arxiv.org/html/2505.14125v3#A3).

[JDCL, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Skiers_Joint_Diffusion_Models_in_Continual_Learning_ICCV_2025_paper.html) is the nearest technical comparison for the joint generation/classification platform. Its [author-preprint v3 methods](https://arxiv.org/html/2411.08224v3#S4) use local new-task training followed by global consolidation from examples generated by both local and previous global models, with classifier and denoiser distillation. The ordinary common learner's current real data plus previous generated replay is a different data flow. Neither that platform nor the three phases below should be labeled a faithful JDCL reproduction. These departures define the adaptation evaluated here.

The cognitive commitment is functional: acquisition uses temporary control and consolidation transfers its effect into prediction that no longer needs that control. No claim identifies diffusion timesteps with biological time, transformers with cortical regions, or teacher copies with hippocampal mechanisms. A benchmark gain would support an engineering claim; behavioral or neural claims need additional evidence.

## Three phases per experience

1. **Joint learning.** Run the existing joint training procedure on current examples and permitted old replay. The previous-experience teacher supplies existing retention targets. On the first experience, old-task retention is inapplicable. Preserve the full expanded student support in old-class KD: restricting and renormalizing the student to old classes would change the objective.
2. **Modulation acquisition.** Freeze the acquired network. Learn only newly introduced classes' modulation variables. A seeded shuffled cycle selects each new class before starting the next cycle; per-class application counts expose budgets too short to visit every class. For a selected class, apply one shared modulation to its positive and balanced negative examples. Earlier bank entries remain fixed. The bank persists across experiences and its storage grows with class count.
3. **Semantic consolidation.** Freeze the bank and a physically independent snapshot of the acquired target network. Train the unmodulated classification projection/head and a predictor. Default variable ownership leaves the denoising trunk fixed. The prior-task retention teacher and acquired target have different roles and must not be confused. `stop_gradient` alone is insufficient if target weights or nontrainable state can still change.

Final prediction uses the unmodulated branch, no task identity, no true-class modulator, and every class seen so far. Null conditioning is shared across semantic target/student views. The bounded implementation rejects unsupported EMA, progressive growth, and stochastic variational flattening. Recovery retains the bank, controller and observer records at completed tasks. An optional positive checkpoint interval also restores committed optimizer steps during joint learning, acquisition and consolidation, including scheduled replay and elapsed-budget controls. Recovery is an implementation property, not evidence of learning efficacy; downtime, unknown abandoned work and unmeasured checkpoint-write duration must be distinguished from committed active training time. A separate shared-backbone ablation deliberately relaxes the default denoiser-invariance constraint.

## Mathematical specification

Let $h_i\in\mathbb{R}^d$ be the existing classifier hidden projection of a frozen acquired feature for example $i$. A positive hidden-projection ratio is required. For class $c$, raw trainable vectors $a_c,b_c$ define

$$
\gamma_c=\mathbf{1}+L_g\tanh(a_c),\qquad
\beta_c=L_b\tanh(b_c),\qquad
m_c(h)=\gamma_c\odot h+\beta_c,
$$

where $L_g,L_b\geq0$ are the configured gain/bias limits and operations are elementwise. This bounds gain deviation and bias, not the feature itself. Normalization returns a unit vector for nonzero rows and zero for zero rows; the implementation first scales by the largest absolute component to avoid overflow. The persistent gain/bias state requires $2Cd$ float32 scalars for $C$ classes, before optimizer state, serialization, and metadata.

For selected class $c$, let $P_c$ and $N_c$ denote sampled positive and negative input indices. With $z_i$ the normalized $m_c(h_i)$, the acquisition loss is

$$
\mathcal L_{\rm acq}(c)=
\frac{1}{|P_c|(|P_c|-1)}
\sum_{\substack{i,j\in P_c\\i\ne j}}(1-z_i^\top z_j)
+\frac{\lambda_o}{|P_c||N_c|}
\sum_{i\in P_c,j\in N_c}(z_i^\top z_j)^2.
$$

The first term attracts distinct selected-class examples; the second, weighted by the configured $\lambda_o>0$, encourages their orthogonality to negatives. Both receive the **same** modulation. This prevents a separate true-label-conditioned bias from revealing each row's answer. Positive self-pairs are excluded. The squared cross-class cosine is a smooth **OPL-inspired variant**: TMCL uses absolute cosine. The per-pair orthogonality minimum agrees, but gradients and joint tradeoffs differ. In the [official OPL implementation](https://github.com/Dendritic-Learning-Group/tmcl/blob/2cb306cc5cbe6d13a3dd4991998ee3e7c2948c8b/tmcl/nn/losses/contrastive_opl.py), `square_loss=True` squares both the positive distance and the negative cosine; the local linear-positive/squared-negative objective is therefore not that switch either. Finite affine modulation cannot guarantee perfect separation for arbitrary input geometry. Unsupported positive/negative counts must fail or be skipped with explicit reporting.

For a batch of $B$ distinct indices, let $q_i$ be the normalized predictor output from the student unmodulated projection, and let $k_j^{(v)}$ be the normalized frozen modulated target for target view $v$. One focus-class modulation is shared across target rows. Matching input indices are positives across views; other batch indices are negatives:

$$
\ell_i^{(v)}=-\log\frac{\exp(q_i^\top k_i^{(v)}/\tau)}
{\sum_{j=1}^{B}\exp(q_i^\top k_j^{(v)}/\tau)},\qquad \tau>0.
$$

Use stable log-sum-exp evaluation. Distinct indices can still depict the same class: same-class false negatives are part of this instance-contrastive adaptation, not a supervised contrastive objective. Repeated copies of one index should not be introduced as artificial negatives. A singleton batch supplies no informative negative.

Acquisition's selected-class attraction can conflict with instance discrimination.
If, for a target view, the positive belongs to a group of $P$ identical normalized targets,
then at least $P$ denominator terms equal the positive exponential, giving
$\ell_i^{(v)}\geq\log P$ for that row, irrespective of predictor capacity. Other
targets can make the bound strict. Thus stronger within-class compactness need
not reduce instance loss, and lower instance loss need not improve class
separation. This is a testable objective choice, not an implementation bug.
The default remains instance InfoNCE; supervised contrastive replacement would
be a separately named treatment with a different interpretation.

With `image_augmentation: tmcl`, each update constructs $V$ independent
geometric/color views of each image once, before diffusion; `augmentation_views`
defaults to $V=4$ and requires $V\geq2$. View one supplies the student, and
views $2,\ldots,V$ supply frozen targets. Image identities and row order remain
matched. At each configured diffusion level, a view $a_v(x_i)$ becomes

$$
x_{i,t}^{(v)}=\sqrt{\bar\alpha_t}a_v(x_i)+
\sqrt{1-\bar\alpha_t}\varepsilon_{i,t}^{(v)}.
$$

Augmentation seeds derive from the phase seed, committed update and view index;
there is no mutable augmentation RNG state to restore. The image views stay
fixed across the noise-level loop within that update. Acquisition uses its own
flip draw before its configured diffusion level. Supervised CE uses a separate
view without geometric/color augmentation at `ce_noise_level`.

The `none` mode preserves the original behavior: one noisy tensor is passed
unchanged to student and target at each level, with one target comparison.
This is the default for direct `RouteSettings()` construction and an explicit
no-augmentation ablation. Maintained CIFAR recipes select `tmcl` explicitly.

This is transfer **under different noise conditions**: each loss pairs student
and target at the same $t$, using independently augmented images in `tmcl`
mode or an identical tensor in `none` mode. No term directly aligns features
at $t\ne s$. It does not directly impose cross-noise invariance or
require a denoiser to discard noise-dependent detail. Default consolidation
updates only the existing classifier projection/head and temporary predictor;
the shared diffusion backbone is fixed. Improvement of a shared sensory or
generative representation cannot be inferred from that treatment.

The noise-aware treatment uses bounded retained-signal weights $w_t=\operatorname{clip}(\bar\alpha_t,w_{\min},1)$. This is a prescribed **noise proxy for semantic reliability**, not a measured probability that a semantic feature is correct. Levels and bounds must be fixed using training/validation information. Route level zero adds no diffusion noise and has weight one, irrespective of whether scheduler index zero ordinarily adds a small amount of noise. Geometric/color augmentation still applies in `tmcl` mode at level zero.

The semantic loss averages weights times per-row losses across selected rows,
target views and configured levels. For `tmcl` mode:

$$
\mathcal L_{\rm mod}=\frac{1}{B|\mathcal T|(V-1)}
\sum_{i=1}^{B}\sum_{t\in\mathcal T}\sum_{v=2}^{V}w_t\ell_{i,t}^{(v)}.
$$

The `none` mode uses the same expression with a single target comparison. Feature-MSE controls replace each InfoNCE term with normalized feature MSE and keep the same averaging. Consequently, increasing the number of levels or target views does not multiply the coefficient by that count. Duplicate levels are rejected by configuration. Dividing by the sum of weights would be a different objective, removing absolute downweighting when all views are unreliable. The weights apply only to semantic transfer. Existing CE, classifier KD, denoising, and noise-KD masks and coefficients keep their own meanings. The review's $\mathcal L_{\rm base}+\lambda_m\mathcal L_{\rm mod}$ is bookkeeping; the implementation reports actual objectives and updates separately for its phases.

Acquisition has a separate fixed `acquisition_noise_level`; consolidation CE has a separate fixed `ce_noise_level`. Both default to no diffusion noise and stay fixed when `noise_levels` varies. Acquisition still receives flips in `tmcl` mode; CE receives no geometric/color augmentation. The implemented consolidation objective is $\lambda_{\rm CE}\operatorname{mean}_i\operatorname{CE}(y_i,p_i)+\lambda_m\mathcal L_{\rm mod}$, with CE evaluated once per sampled batch at its own level. Previous-task classifier/noise KD belongs to the original joint phase and is not recomputed during these semantic phases. Hold image-augmentation mode and view count fixed in a noise-band comparison so it does not also change augmentation or modulation-acquisition inputs.

## Controls and evidence needed

| Condition | Interpretation |
|---|---|
| Learned versus random bank | Tests whether supervised modulation structure matters |
| Identity bank with InfoNCE | Existing random condition with zero initialization; tests transfer without learned or random affine perturbations |
| No consolidation, with replacement CE steps | Tests transfer against additional supervised optimization; not a zero-extra-work baseline |
| Modulated feature distillation | Same frozen modulated targets and predictor, normalized feature MSE instead of InfoNCE; compares pointwise with contrastive transfer |
| Unmodulated feature distillation | Ordinary acquired-target feature transfer without modulation; a distinct control |
| Extra joint training | Tests an alternative use of the additional optimization budget |
| Time-matched joint training | Spends a prespecified measured per-task time allowance on additional joint training; records actual elapsed time and overshoot |
| True-class CE acquisition | Explicit shortcut-prone conditioning control, not the proposed objective |
| Clean versus several noise levels | Tests the proposed diffusion-specific dependence |
| Semantic-only versus shared backbone | Allows gradients into every connected classifier/shared-backbone variable; tests the effects of semantic alignment on shared features and denoising |

The random-bank control executes acquisition gradients with zero learning rate, retaining the initialized bank while matching optimizer applications. Those counted applications do not change modulation parameters. The unmodulated feature-distillation control still executes modulation acquisition but ignores that bank in its targets, making its acquisition a compute control. The pointwise objective averages squared differences over feature dimensions and lies in $[0,4/d]$; its numerical scale differs substantially from InfoNCE. A claim about negatives alone requires a prespecified, equally applied weight-selection procedure or a separate matched-gradient-strength control.

For MSE/InfoNCE selection, declare objective-specific coefficient grids, equal
selection budgets and validation access, a common criterion and tie rule before
looking at results; lock the chosen settings for confirmation. Equal numerical
coefficients do not establish comparable regularization strength. These fixes
neither tune those coefficients nor claim one objective is more effective.
The executable controls in `controls.py` preserve paired stream seeds, class
orders, permitted pools and declared update budgets through the existing study
API. Additional joint training uses ordinary batches rather than the semantic
sampler, so presentations may differ. Replacement CE still computes unused
semantic forwards although only CE gradients affect the deployed head. Report
actual phase draws, time and resource differences alongside equal update counts.

Match optimizer applications across phases and report measured elapsed time: equal counts do not match target forward passes, view counts, or number of affected parameters. Report replay presentations and generation work, persistent bank/predictor/model/teacher/optimizer bytes, and peak memory separately. Tensor-byte accounting excludes allocator/Python overhead and some duplicate runtime buffers; it is not a measured peak. Retaining a class bank is not memory-free. The shared-backbone treatment cannot promise denoiser invariance; denoiser-only variables disconnected from semantic losses still receive no gradients, and generative quality requires separate evaluation.

For the time comparison, obtain acquisition-fit, consolidation-fit, and target-snapshot durations from a separate learned pilot on the same hardware and protocol. Freeze one summed allowance per task in `extra_joint_seconds`. The joint control stops at the first callback-visible training-batch boundary after that allowance and reports overshoot; it cannot simultaneously promise equal updates or FLOPs. Report outer elapsed time separately because data scanning and setup contribute additional overhead.

Example benchmark protocols are CIFAR-10 in five two-class experiences and CIFAR-100 in ten ten-class experiences, with presaved paired seeds/class orders, no future-class training, and validation selected within the allowed training stream. Disclose retained historical validation data. Evaluate clean and ensemble predictions on the same checkpoints. Ensemble accuracy alone is weaker evidence than improved unmodulated clean prediction.

`study.py` materializes complete paired seed/order streams through `common.experiment`, with condition order randomized within blocks. Its default primary contrast is learned minus extra-joint final average accuracy. It validates each executable scientific configuration against the manifest, binds executed and collected run identities to that manifest, and rejects incomplete outcome coverage. Development uses validation matrices; a new frozen confirmation design enables test matrices. Statistical units are complete independent streams, not individual tasks or test images. Paired confidence intervals inherit their distributional assumptions and do not establish an effect from a small pilot alone.

Export the full accuracy matrix, final and average incremental accuracy, old/new accuracy, signed forgetting, and backward transfer. `common.continual_reporting` defines forgetting using the best observation **before the final checkpoint** minus final accuracy, so improvements can produce negative forgetting. Forward transfer is not derivable from the lower triangle alone. Use normalized probabilities for calibration metrics and label hidden-feature diagnostics separately from existing probability-space CKA.

Before interpreting results, verify immutable acquired targets and old bank entries; correct class expansion; absence of label/task inputs at inference; the declared trainable-variable sets; unchanged denoising outputs under semantic-only updates; finite losses and nonzero intended gradients; and save/load equivalence. Collapse probes must inspect actual unmodulated hidden features as well as predictor alignment on fixed held-out examples. Constant vectors can align perfectly; feature variance/spectrum and the constant-prediction contrastive value $\log B$ provide additional checks.

## Diagnostic validity and metric definitions

Schema 2 corrects the original probe's class-ordered batches and batch-index gate
assignment. Image-content canonicalization and seeded class-interleaving produce
reproducible mixed batches independent of input iteration order. Every selected
gate acts on every row of every batch. Gate selection uses only bank IDs,
old/new membership and a seed, not the rows' labels. All gates are measured up
to a configurable cap (default 16); larger banks use balanced old/new slots,
redistributing a group's unused slots. Selected IDs, fractions, batch class
counts, examples and noise levels are exported. These aggregates characterize
only the measured subset. Balanced old/new sampling is not a size-weighted
whole-bank estimate. Functional old-gate coverage is selected and labeled
separately. Class balancing itself is legitimate held-out sampling and is not
an inference-time class input.

For each fixed batch/gate/noise comparison, `hidden_infonce` inserts the raw
unmodulated hidden projection in place of $q$ in the normalized instance loss
above. `hidden_target_cosine` is its mean matched-row target cosine. Both are
predictor-free at both endpoints. `predictor_infonce` and
`predictor_target_cosine` instead use the same temporary predictor evaluated
before and after optimization. Its initialized identity state is measured
before training. Predictor gains alone are training-only outcomes because the
predictor is discarded. Frozen target features and exact stateless noise
tensors are cached; no diagnostic randomness advances the training RNG.
Aggregates weight batch means by row count and then equally weight selected
gates/noise levels, without reliability weights. Negative support is local to
each batch and is reported; different probe batch sizes need not have comparable
absolute InfoNCE values. The unmodulated-MSE ablation explicitly marks targets
as unmodulated; repeated gate IDs there do not measure modulation effects.

A controlled counterexample uses $H=I_4$, a row-permuted target $K$, and
$\tau=0.1$. Replacing an identity predictor by a kernel mapping $H$ to $K$
reduces predictor-mediated InfoNCE from approximately 10.000136 to 0.000136.
The deployed hidden features, their raw InfoNCE/cosine, class geometry, collapse
statistics and clean classification are identical. This is now a regression;
the former mixed-convention `unweighted_infonce` field was removed, not renamed
as evidence of transfer. Historical values cannot support that interpretation.

For normalized hidden rows $z_i$, within-class compactness is the mean
$1-z_i^\top z_j$ over same-class ordered pairs $i\ne j$. Between-class
separation is the mean of the same distance over different-class pairs; its
squared-cosine counterpart separately measures orthogonality and cannot hide
positive/negative cosine cancellation. Smaller within distance and larger
between distance indicate separation; smaller squared cosine indicates
orthogonality, a distinct criterion. Reports include all, old-only, new-only,
old/new-cross and per-class scopes with pair counts. Empty pair sets produce
`null`, not zero. Roundoff is clipped to cosine support. Zero features follow
the objective's zero normalization, so distance alone is insufficient: clean
accuracy, mean normalized channel standard deviation, centered effective rank
and off-diagonal cosine are retained. Effective rank uses entropy of normalized
singular values of centered normalized features, with zero assigned to an
exactly constant cloud. No predictor participates in these deployed measures.

Old gates are evaluated at three clean-input boundaries using the same permitted
validation cohort: after head expansion/before joint training, after joint
training, and after consolidation. Each measured gate's selected-class
attraction and positive-versus-rest squared cosine use the same equations as
acquisition, with separate component and pair counts; corresponding unmodulated
values are reported. Unmodulated hidden MSE-change/CKA and geometry deltas
separate feature drift from gate parameter preservation. Deltas are later minus
earlier within each phase. The consolidated model's default frozen denoising
path is still checked separately. No gate is retrained, no unavailable old
training image is fetched, and no additional teacher is stored for diagnostics.
Only bounded validation arrays/features are temporarily cached and accounted.

These are descriptive phase changes, not an isolation of InfoNCE's causal
contribution: consolidation also includes CE. Head-expansion effects are outside
the pre/post-joint comparison, rest cohorts may change between tasks, and clean
functional probes do not cover noisy gate behavior. Missing validation, absent
class positives, discarded gates or a missing pre-joint hook are reported as
unavailable. Unchanged hashes establish parameter preservation, never preserved
class-separation function. Mechanistic controls and replicated experiments are
still required to explain any measured changes.

The principal positive result would be lower old-class error at comparable new-class learning, transferred into the unmodulated clean branch and reproducible across seed/order pairs under resource and random-modulation controls. Three independent repeats give limited precision; report the actual sample count, paired effects and uncertainty. Additional repeats or datasets can strengthen evidence but are separate extensions to a prespecified study. A result that disappears with matched updates, is reproduced by random modulation, or prevents new-class learning favors a simpler explanation and should be reported accordingly.
